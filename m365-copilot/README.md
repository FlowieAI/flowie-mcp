# Flowie for Microsoft 365 Copilot

The package Microsoft asks for to certify Flowie's app MCP server (`https://back.p2p-flowie.com/agent-hub/mcp`) and list it in Copilot Studio, Microsoft Foundry and Microsoft 365 Copilot. Process: [Microsoft MCP server certification (preview)](https://learn.microsoft.com/microsoft-copilot-studio/mcp-certification). Offer type in Partner Center: **Apps and Agents for M365 and Copilot**.

| File | What it is |
|---|---|
| `manifest.json` | Microsoft 365 app manifest v1.30, one `agentConnectors` entry for the remote MCP server. Validates against the v1.30 schema. |
| `mcptools.json` | The server's `tools/list` (name, title, description, input schema, annotations). |
| `intro.md` | Public documentation: prerequisites, sign-in, operations, prompts, known limitations. |
| `color.png`, `outline.png` | 192x192 color icon, 32x32 white-on-transparent outline icon. Generated by `build.py`. |
| `SUBMISSION.md` | Copy-ready intake form answers, Partner Center listing and test notes (no credentials: this repository is public). |
| `build.py` | Renders the icons, checks that the manifest and tool file are ASCII only (Microsoft rejects anything else), zips `dist/flowie-m365.zip`. `--refresh-tools` re-reads `tools/list` with `FLOWIE_TOKEN`. |

```bash
pip install resvg-py requests
python build.py
```

## Sign-in

Microsoft's certification path signs in with OAuth 2.0 through an **Azure Key Vault** that holds the client configuration. Microsoft does not support PKCE there, so it uses a **confidential client** of Flowie's authorization server: client id `microsoft-copilot-mcp`, an entry in exchange-api's `CONFIDENTIAL_OAUTH_CLIENTS` (only the SHA-256 of the secret is configured), the same mechanism as the Azure Bot Service client. The entry carries `"resource": "https://back.p2p-flowie.com/agent-hub/mcp"` (exchange-api#473): Microsoft cannot add `resource=` to the authorization URL, and without it the client would get an Exchange key, which this server refuses.

Key Vault secrets (names are case-sensitive):

| Secret | Value |
|---|---|
| `ClientId` | the confidential client id |
| `ClientSecret` | its secret |
| `AuthorizationUrl` | `https://back.p2p-flowie.com/exchange/oauth/authorize` |
| `TokenUrl` | `https://back.p2p-flowie.com/exchange/v1/oauth/token` |
| `RefreshUrl` | `https://back.p2p-flowie.com/exchange/v1/oauth/token` |

The vault grants **Key Vault Secrets User** to Microsoft's service principal `8e91e74f-afe9-41cd-8c3f-17a9562a74ea`. `manifest.json` names the vault `https://flowie-mcp-kv.vault.azure.net/`; change `authorization.referenceId` if the vault gets another name.

The confidential client's redirect URIs are Microsoft's callbacks: `https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect` and `https://global.consent.azure-apim.net/redirect`. No `Scopes` secret is needed: a request without scopes gets the user's full Flowie permissions, as in the app.
