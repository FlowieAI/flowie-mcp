Ask about Flowie: sending compliant invoices in 150 countries through Sovos, order-to-cash, procure-to-pay, supplier management (SRM), integrations and security. Read-only, **no sign-in needed**.

```bash
claude mcp add --transport http flowie https://get-flowie.com/mcp
```
